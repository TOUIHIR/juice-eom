# SÈVE — Premium Cold-Pressed Juices

SÈVE is a luxury e-commerce landing page experience for a high-end cold-pressed juice brand. The project focuses on a "fruit-first" philosophy, emphasizing purity, freshness, and a minimalist, solar-inspired aesthetic.

## 🌟 Key Features

- **Immersive Visuals**: High-performance animations including a custom canvas-based hero section, parallax scrolling effects, and interactive 3D-like fruit presentations.
- **Dynamic Product Experience**: Dedicated landing pages for different juice varieties (Mangue, Lemon, Berries) with tailored color palettes and imagery.
- **Interactive Elements**:
    - **Loading Sequence**: A custom "liquid" loader that simulates the preparation of the juice.
    - **Product Ring**: A rotating navigation system to switch between different juice flavors.
    - **Flip Cards**: Interactive information grids explaining ingredients, benefits, and taste.
- **Integrated Shopping Cart**: A functional slide-out drawer for managing product selection, sizes, and quantities.
- **Responsive Design**: A mobile-first approach ensuring the premium experience translates across all device sizes.

## 🛠️ Technical Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript.
- **Typography**: Uses *Cormorant Garamond* for an elegant, editorial feel and *Manrope* for modern readability.
- **Animations**: Custom JS-driven animation loops, CSS transforms, and Canvas API.

## 📁 Project Structure

- `index1.html`, `index2.html`, `index3.html`: Entry points for the different fruit varieties.
- `style1.css`, `style2.css`, `style3.css`: Variety-specific styling.
- `script1.js`, `script2.js`, `script3.js`: Logic for animations and cart functionality.
- `/berries`, `/lemon`, `/mango`: Directories containing frame-by-frame image sequences for smooth animations.

## 🚀 Getting Started

Since this is a static frontend project, you can run it simply by opening any of the `index.html` files in a modern web browser:

1. Clone the repository.
2. Open `index1.html` (Mango), `index2.html` (Lemon), or `index3.html` (Berries) in your browser.

## 🎨 Design Philosophy

SÈVE aims to evoke the feeling of "sunshine in a bottle." The design uses:
- **Solar Palettes**: High-contrast, vibrant colors mapped to the specific fruit.
- **Glassmorphism**: Subtle blur and transparency effects to mimic the look of cold glass and fresh juice.
- **Organic Motion**: Fluid transitions that reflect the natural state of the product.
